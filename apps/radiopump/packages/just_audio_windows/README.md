# Локальная поправка just_audio_windows

Исходник: `just_audio_windows` 0.2.3, [репозиторий автора](https://github.com/bdlukaa/just_audio_windows).
Лицензия MIT сохранена в `LICENSE`. Это Windows-плагин для системного WinRT
MediaPlayer; дополнительных медиадекодеров он не поставляет.

Изменения RadioPump в `windows/player.hpp`:

- Нулевая `NaturalDuration` больше не превращает начальную нулевую позицию
  бесконечного MP3-потока в `completed`.
- Мгновенное нативное состояние Paused/Buffering не переопределяет `playing`
  в Dart: оно могло отменить вызов play(), ещё ожидающий AudioSession. Фактическая
  готовность по-прежнему передаётся через processingState, намерение — из Dart.
- Неизвестная длительность передаётся как null, а не 0: иначе just_audio
  ограничивает позицию нулём и наш watchdog ошибочно переподключает живой эфир.

Реальный обрыв восстанавливается общим watchdog/retry клиента. Системное
управление Windows отдельно не добавлено; используются кнопки окна и трея.

Плагин хранится в проекте, чтобы сборки воспроизводили исправление без ручного
редактирования pub cache. При обновлении upstream нужно перепроверить прямой эфир
без Content-Length, остановку и многократное переключение волн.
